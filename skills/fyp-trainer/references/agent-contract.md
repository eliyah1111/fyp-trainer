# Agent Contract

FYP Trainer is engine-neutral. Agents integrate through CLI commands, JSON files, and the exported ESM API in `src/index.js`.

## Inputs

- User taste request: free text describing aesthetics, creators, sounds, interests, and unwanted content.
- Optional profile id: saved in `memory/profiles.json`.
- Optional profile JSON file: pass with `--profile=<path>`.

## Outputs

- Profile JSON: generated by `node ./src/cli.js profile --input="..." --json`.
- Session JSON: written to `sessions/session-*.json`.
- Diagnostic JSON and PNG: written to `sessions/diagnostic-*`.

## Required Confirmation

Agents must show the generated profile summary to the user and receive confirmation before calling live `train` without `--dry-run`.

## Stable CLI Surface

```bash
node ./src/cli.js profile --input="<request>" --json
node ./src/cli.js plan --id="<profile-id>"
node ./src/cli.js train --id="<profile-id>" --confirmed --duration=60
node ./src/cli.js train --profile="./memory/profile.json" --dry-run --duration=30
node ./src/cli.js diagnose --isolated --query="cinematic fashion"
```

## Stable ESM Surface

```js
import {
  analyzeFypRequest,
  buildSessionPlan,
  runTrainingSession,
  runTikTokDiagnostic
} from "./src/index.js";
```
